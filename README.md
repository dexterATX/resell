# SkyResell

SkyResell is a modern Astro site foundation for reselling airline tickets at a discounted flat rate.

## Requirements

- [Bun](https://bun.sh/) installed locally

## Commands

Install dependencies:

```sh
bun install
```

Start the development server:

```sh
bun run dev
```

Build for production:

```sh
bun run build
```

Preview the production build:

```sh
bun run preview
```

Run Astro type checks:

```sh
bunx astro check
```

## Project Structure

```text
public/             Static assets, including the favicon
src/assets/         Source assets for Astro components
src/components/     Reusable UI components
src/layouts/        Shared page layouts
src/pages/          File-based Astro routes
src/styles/         Global styles and Tailwind CSS entrypoint
```
