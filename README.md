# FLATFARE Astro Marketing Site

A modern Astro and Bun foundation for a discounted flat-rate airline ticket reseller: one transparent flat price regardless of route.

## Commands

```bash
bun install
bun run dev
bun run build
bun run preview
```

- `bun run dev` starts Astro on the Bun runtime via `bunx --bun astro dev`.
- `bun run build` creates the production site in `dist/`.
- `bun run preview` serves the production build locally on the Bun runtime.

## Project Structure

```text
src/components/   Section components for future beads
src/layouts/      Shared layouts for future beads
src/pages/        Astro pages
src/styles/       Tailwind v4 entrypoint and design system
public/           Static assets and favicon
```
